# URL shortener API mock kit

A URL-shortener contour (shorten, expand, stats) — mock a link-shortening backend.

    mockarty-cli plugin install mockarty.url-shortener-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.url-shortener-kit

Instantiate kit `url_shortener_api` from the Mock Kits catalogue.
