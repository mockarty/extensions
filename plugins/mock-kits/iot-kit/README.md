# IoT API mock kit

An IoT device contour (devices, telemetry, commands) — mock a device-management backend for IoT dashboards.

    mockarty-cli plugin install mockarty.iot-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.iot-kit

Then instantiate the kit `iot_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
