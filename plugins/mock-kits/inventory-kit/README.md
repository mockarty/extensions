# Inventory API mock kit

A warehouse/inventory contour (products, stock levels, warehouses) — mock an inventory backend for commerce flows.

    mockarty-cli plugin install mockarty.inventory-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.inventory-kit

Then instantiate the kit `inventory_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
