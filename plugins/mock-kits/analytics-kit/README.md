# Analytics API mock kit

An analytics contour (event ingest, funnels, metrics) — mock an analytics backend for dashboards.

    mockarty-cli plugin install mockarty.analytics-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.analytics-kit

Then instantiate the kit `analytics_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
