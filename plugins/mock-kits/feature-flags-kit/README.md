# Feature flags mock kit

A feature-flag service contour (list flags, evaluate) — mock LaunchDarkly/Unleash-style flag evaluation.

    mockarty-cli plugin install mockarty.feature-flags-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.feature-flags-kit

Then instantiate the kit `feature_flags` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
