# Booking API mock kit

A reservations contour (availability, create/cancel reservation) — mock a booking backend for calendar/hotel/restaurant apps.

    mockarty-cli plugin install mockarty.booking-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.booking-kit

Then instantiate the kit `booking_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
