# CRM API mock kit

A CRM contour (contacts, companies, deals) — mock a Salesforce/HubSpot-style sales API.

    mockarty-cli plugin install mockarty.crm-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.crm-kit

Then instantiate the kit `crm_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
