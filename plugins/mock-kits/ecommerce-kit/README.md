# ecommerce-kit — Products/Cart/Orders (mock-kit example)

A second declarative mock-kit example: a whole e-commerce contour
(`/products`, `/cart`, `/orders`) in one enable. No code.

    mockarty-cli plugin pack .
    mockarty-cli plugin install mockarty.ecommerce-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.ecommerce-kit
