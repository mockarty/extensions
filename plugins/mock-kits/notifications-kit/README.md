# Notifications API mock kit

A notifications contour (send push/email/sms, templates) — mock a notification-service backend.

    mockarty-cli plugin install mockarty.notifications-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.notifications-kit

Then instantiate the kit `notifications_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
