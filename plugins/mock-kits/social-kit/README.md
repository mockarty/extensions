# Social API mock kit

A social-network contour (posts, comments, likes, followers) — mock a social feed API for client development.

    mockarty-cli plugin install mockarty.social-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.social-kit

Then instantiate the kit `social_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
