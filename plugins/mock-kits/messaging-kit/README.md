# Messaging API mock kit

A messaging-provider contour (send SMS/email, delivery status) — mock Twilio/SendGrid-style delivery for notification flows.

    mockarty-cli plugin install mockarty.messaging-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.messaging-kit

Then instantiate the kit `messaging_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
