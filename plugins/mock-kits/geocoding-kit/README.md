# Geocoding API mock kit

A geocoding contour (forward + reverse) returning coordinates and addresses — mock a maps/geocoding provider.

    mockarty-cli plugin install mockarty.geocoding-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.geocoding-kit

Then instantiate the kit `geocoding_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
