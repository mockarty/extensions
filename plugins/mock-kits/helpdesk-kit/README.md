# Support/helpdesk API mock kit

A helpdesk contour (tickets, agents, replies) — mock a support-desk backend (Zendesk-style).

    mockarty-cli plugin install mockarty.helpdesk-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.helpdesk-kit

Instantiate kit `helpdesk_api` from the Mock Kits catalogue.
