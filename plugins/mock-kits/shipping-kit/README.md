# Shipping API mock kit

A shipping/logistics contour (rates, labels, tracking) — mock a carrier API for fulfillment flows.

    mockarty-cli plugin install mockarty.shipping-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.shipping-kit

Then instantiate the kit `shipping_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
