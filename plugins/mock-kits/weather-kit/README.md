# Weather API mock kit

A weather-service contour (current conditions + multi-day forecast) with dynamic values — mock a weather provider for app development.

    mockarty-cli plugin install mockarty.weather-kit-1.0.0.zip
    mockarty-cli plugin enable mockarty.weather-kit

Then instantiate the kit `weather_api` into any namespace from the Mock Kits catalogue (UI or MCP `mock_kit_instantiate`).
