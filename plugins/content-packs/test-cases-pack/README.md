# test-cases-pack

A content pack for the **TCM** module — instantiate it to seed manual test cases (with steps).

    mockarty-cli plugin install mockarty.test-cases-pack-1.0.0.zip
    mockarty-cli plugin enable mockarty.test-cases-pack

Then instantiate `starter_cases` from the Content Packs catalogue. Requires the TCM feature.
