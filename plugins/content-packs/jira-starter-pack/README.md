# jira-starter-pack

A content pack for the **Issue Tracker** — instantiate it to seed a starter project (SAMPLE) with an epic, stories, a bug and a task.

    mockarty-cli plugin install mockarty.jira-starter-pack-1.0.0.zip
    mockarty-cli plugin enable mockarty.jira-starter-pack

Then instantiate `jira_starter` from the Content Packs catalogue.
