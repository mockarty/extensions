# api-collection-pack

A content pack for the **API Tester** module — instantiate it to seed an HTTP collection of sample requests.

    mockarty-cli plugin install mockarty.api-collection-pack-1.0.0.zip
    mockarty-cli plugin enable mockarty.api-collection-pack

Then instantiate `http_smoke` from the Content Packs catalogue. Requires the API Tester feature.
