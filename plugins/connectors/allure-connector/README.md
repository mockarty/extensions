# Allure TestOps connector

A ready-to-use Allure TestOps connector — reuses the built-in Allure adapter to push launches and results.

    mockarty-cli plugin install mockarty.allure-connector-1.0.0.zip
    mockarty-cli plugin enable mockarty.allure-connector

Then create an integration from the connector `allure_testops` (Integrations → New → from connector) and add your credentials per-namespace.
