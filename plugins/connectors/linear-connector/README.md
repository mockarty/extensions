# Linear connector

A ready-to-use Linear connector — reuses the built-in Linear adapter to link Mockarty issues/tests to Linear.

    mockarty-cli plugin install mockarty.linear-connector-1.0.0.zip
    mockarty-cli plugin enable mockarty.linear-connector

Then create an integration from the connector `linear_team` (Integrations → New → from connector) and add your credentials per-namespace.
