# TestRail connector

A ready-to-use TestRail connector — reuses the built-in TestRail adapter to sync cases and runs.

    mockarty-cli plugin install mockarty.testrail-connector-1.0.0.zip
    mockarty-cli plugin enable mockarty.testrail-connector

Then create an integration from the connector `testrail_project` (Integrations → New → from connector) and add your credentials per-namespace.
